# NitroShock

**Pay-as-you-go SEO and AI visibility platform.**

Rank tracking, site audits, keyword research, backlink analysis, AI visibility monitoring and content tools, paid per use with credits. No subscription, and credits never expire.

### Platform

- **Web app** - [nitroshock.ai](https://nitroshock.ai/)
- **Free tools** - [SEO tools with no signup](https://nitroshock.ai/free-tools/)
- **WordPress plugins** - [Page Builder, ShockMeta, NitroImg and more](https://nitroshock.ai/plugins/)

### Open source

- **[NitroLiteBox](https://github.com/NitroShockAI/NitroLiteBox)** - a zero-dependency image lightbox for WordPress. Vanilla JS, loads only on pages that use it. [Plugin page](https://nitroshock.ai/nitrolitebox/)
