### Detect. Fix. Build. Rank.

Most SEO tools hand you a to-do list. NitroShock connects the finding to the fix: Site Audit results map to fixes in the WordPress plugins (meta and schema through ShockMeta, oversized images through NitroImg, duplicate content through NitroEcho), and the Page Builder writes new pages from live search data.

### Open source

**[NitroLiteBox](https://github.com/NitroShockAI/NitroLiteBox)** is a fast full-screen image lightbox for WordPress. Vanilla JS with zero dependencies, pinch and scroll zoom, keyboard and swipe navigation, and it only loads on pages that use it. GPL v2.
